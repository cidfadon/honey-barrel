Aktualna sekcja Documentation czyta tylko pliki .md z katalogów publicznych:

Dla wersji angielskiej — wrzuć plik do public/docs/
Dla wersji polskiej — wrzuć plik do public/docs/pl/
Dodaj nazwę pliku do listy w public/docs/index.json (np. "MOJ_DOKUMENT.md")
Odśwież stronę — dokument pojawi się w menu po lewej.

W sekcji Documentation jest teraz osobna lista „PDF documentation”; wystarczy wrzucić pliki do public/docs/pdf/ i dopisać ich nazwy do public/docs/pdf/index.json, a pojawią się jako linki do pobrania.
